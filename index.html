How to use it

Three steps

  1. Open Shipment Prediction and enter transit time, number of legs, package type and fill ratio. The result updates as you type.
  2. Read the risk and its band. Then check What if to see how a shorter trip, fewer hand-offs or other packaging changes it.
  3. Optionally enter a known number of door opens to see the risk for that handling.

The model only uses four inputs known before shipping. Sensor readings such as temperature and humidity are only known after the trip, so they are not model inputs.
